# Card images

This folder holds the 78 Rider–Waite–Smith card images (1909, public domain in
the US and UK). Sage reads them from here by default, which is why the app works
with no internet connection.

Any file that is missing falls back to Wikimedia Commons automatically, one image
at a time — so a gap here degrades gracefully rather than breaking anything.

**To use scans of your own deck**, replace the files below with your own, keeping
the filenames exactly as they are. You can do it a few cards at a time. Portrait
orientation, roughly 2:3.4, JPEG; around 500px wide is plenty.

Run **Settings → Check all 78 images** at any point to see exactly which files
loaded and which did not.

Settings also has a Wikimedia option if you would rather not ship the images at
all — that one needs a working connection.
